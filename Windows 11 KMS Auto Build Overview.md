## ⚙️ Paano Ito Gumagana (How It Works)

Gumagamit ang **KMS Auto** ng isang *Key Management Service* emulation. Sa halip na humingi ng aktibasyon mula sa malalayong server, ang tool ay gumagawa ng "local host" sa iyong computer. Binibigyan nito ang Windows at Microsoft Office ng mga valid na sertipiko upang manatiling aktibo nang permanente o pangmatagalan.

## 🚀 Hakbang-hakbang na Gabay (Step-by-Step Guide)

**Hakbang 1 — Ihanda ang Kapaligiran**
Bago simulan, pansamantalang i-off ang iyong antivirus at firewall. Maraming security tool ang nagba-block sa KMS files dahil ito ay binabago ang system configuration.

**Hakbp 2 — I-extract ang Build**
Gamit ang WinRAR o 7-Zip, buksan ang folder na idinownload. Siguraduhin na hindi kulang ang anumang file sa loob nito.

**Hakbang 3 — Patakbuhin bilang Admin**
I-right click ang `KMSAuto_Setup.exe` at piliin ang **"Run as Administrator"**. Mahalaga ito upang magkaroon ng tamang pahintulot ang system sa pagbabago ng mga files.

**Hakbang lang — Piliin ang Produkto**
Pumili kung nais mong i-activate ang Windows, Office, o pareho. Maghintay ng ilang segundo hanggang sa matapos ang proseso.

**Hakbang 5 — I-restart ang PC**
Kapag lumitaw na ang "Activation Successful," i-restart ang iyong kompyutera upang maitala ang bagong lisensya sa system.
